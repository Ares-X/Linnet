原样直达当前应用

  • Shift 中文与英文之间
  • Caps Lock 原始 ASCII

特点

  • 一源三态：中文、Smart English、ASCII
  • 全拼与七种双拼，学习数据共用
  • 英文补全、纠错、音标与释义
  • 程序与词包分离，日常更新约 7 MB
  • 七套候选主题，随系统浅色 / 深色

隐私

无账号，无遥测，无在线翻译。 字词与学习默然留在本机 ~/Library/Application Support/Linnet/。 若需要，可用 iCloud 仅同步学习词。

安装

社区版未经 Apple Developer ID 签名或公证。 请自 GitHub Release 取得安装包，并核对 SHA-256。 初次安装后注销并重新登录一次即可登记输入源。 位置：~/Library/Input Methods/Linnet.app
