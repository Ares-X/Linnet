按你习惯的方式写

写中文

继续用熟悉的全拼或双拼。遇到英文单词，直接敲进去，一句话可以连续写完。八种方案共享词库与学习记录，有歧义时再从候选中选择。

全拼 · 自然码 · 小鹤 · 微软 · 搜狗 · 智能 ABC · 紫光 · 拼音加加

写英文

输入时，Smart English 会给出补全与拼写建议，还可以查看音标、中文释义和下一词预测。你写下的原文也会保留在候选中。

写下的文字，留在本机。

日常输入不需要联网，也不用注册账户。词库、学习记录与备份保存在本机，不采集遥测。想在不同 Mac 上延续输入习惯时，可以选择 iCloud 学习词同步。

隐私与数据说明 ↗

留下常用的表达

把常用的名字和专有名词加进个人词典。地址、签名或常写的一段话，也能设成短码，几下按键就可展开。

更新后，继续用就好

程序更新时，已有词库与模型可以继续使用。在设置中应用 Core 更新后，不必注销，也不必重新添加输入源。

下载 macOS 版 版本说明与文件校验 ↗
  1. 1

    安装 Linnet.pkg

    从本项目 GitHub Release 获取安装包。社区版未获 Apple Developer ID 签名或公证；若被系统拦截，请按安装指南手动确认信任。

  2. 2

    注销并重新登录

    首次安装成功后，保存工作并重新登录，让 macOS 完成输入源登记。后续设置内 Core 更新无需注销。

  3. 3

    启用 Linnet

    在系统设置 → 键盘 → 文本输入中添加或启用 Linnet，按提示允许，再从菜单栏输入菜单选中它。

完整安装指南 ↗
核对安装包的 SHA-256

在下载目录执行以下命令，将结果与同一 Release 提供的 SHA-256 比较。

shasum -a 256 Linnet.pkg
